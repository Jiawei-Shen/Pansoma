The input was the providers' GRCh38 alignments (GIAB, SMaHT, CASTLE) of the reads Pansoma used; we aligned the SEQC2 Illumina reads ourselves. The reference was GRCh38 (the no-alt analysis set for HCC1395), and calling was restricted to chr1 (plus chr20 for HCC1395). ClairS-TO has no dorado SUP v5 model, so HG008T ONT used its SUP v4.2 model. The original HG008T ONT DeepSomatic-TO run had used the PacBio model. The revision uses a repeat run with `ONT_TUMOR_ONLY`.
- **Population resources and PASS.** DeepSomatic-TO receives population allele frequencies as an input channel (DeepVariant 1000 Genomes calls for Illumina, CoLoRSdb for long reads; AF > 0.05), and we enabled its default panel-of-normals filter (`--use_default_pon_filtering=true`). ClairS-TO used its default tagging (gnomAD and CoLoRSdb AF ≥ 0.001, dbSNP 138 non-somatic sites, the GATK 1000 Genomes panel of normals) and its default quality filters. All other options were left at their defaults. For both tools, PASS means FILTER = PASS.
- **Scoring.** We score every call set with Pansoma's protocol (same truth, benchmark regions and rtg vcfeval options) in three settings: native PASS; PASS after the same population filtering; and all records after that filtering, ranked by QUAL. The last setting gives recall at matched precision (R1.6).
