# Audit decisions (2026-10-05)

Two independent audits checked the first version of this analysis:

- **numbers**: every table and prose number recomputed with the auditor's own code.
- **normal_frame**: c3 re-derived on 114 random and 14 named loci, with raw-contig sequences and the auditor's own
  anchors, aligner and class code.

Their scripts and tables are in `$D/audit/{numbers,normal_frame_indep}/`
(`$D = /scratch/jshen/data/pansoma_net_v2_runs/graph_absorbed_somatic_colo829t_20261005`). The first version's outputs
are frozen in `$D/prefix_20261005/`.

Each finding was re-checked here before acting on it. Fixes went into `c3_normal_frame.py` and `c4_tables.py`; c3 and c4
were re-run; `per_variant.tsv`, `columns.tsv`, `repeat_context.md` and `README.md` were regenerated by c4.

## Not changed

- The patient-frame event is still derived from the closest normal haplotype (HG008T used the GIAB INFO event). The
  README says so in the Definitions table and in section 6.
- A dipcall copy is assumed to be the patient's own copy. No segmental-duplication track was used.
- The imperfect-VNTR thresholds are the auditor's (k = 12, 7-150 bp, 60 % over +-15 bp, run >= 40 bp, >= 20 bp beyond the
  array). They were not tuned.
